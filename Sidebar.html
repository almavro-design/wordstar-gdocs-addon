WordStar Commands

Navigation

Ctrl+ALeft one character
Ctrl+DRight one character
Ctrl+EUp one line
Ctrl+XDown one line
Ctrl+SLeft one word
Ctrl+FRight one word
Ctrl+RPage up
Ctrl+CPage down
Ctrl+WScroll up (cursor stays)
Ctrl+ZScroll down (cursor stays)

Line Operations (Ctrl+Q...)

Ctrl+Q+RBeginning of line
Ctrl+Q+CEnd of line
Ctrl+Q+HDelete to beginning of line
Ctrl+Q+YDelete to end of line

Editing

Ctrl+HDelete character backward
Ctrl+GDelete character forward
Ctrl+TDelete word forward
Ctrl+YDelete entire line
Ctrl+NInsert line break
Ctrl+JInsert hard return
Ctrl+VToggle overwrite mode

Mode & Status

Overwrite mode: OFF

Note: This is an alpha version. Some commands (especially Ctrl+W, Ctrl+Z scroll, and multi-key sequences) need client-side JavaScript enhancement.
